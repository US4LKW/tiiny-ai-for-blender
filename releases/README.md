# Ready-to-install Blender Extension

**`tiiny_ai_for_blender-0.1.0.zip` is the Blender installer.** Its root contains `blender_manifest.toml`, `__init__.py` and `LICENSE`.

Install via **Blender → Edit → Preferences → Get Extensions → Install from Disk** and select the ZIP without extracting it.

Do not confuse this file with the GitHub-generated **Source code (zip)**. Those files contain the repository source, not the ready-to-install package.

Read the [Complete Illustrated User Guide](../docs/USER_GUIDE.md), the [Release Notes](../RELEASE_NOTES_v0.1.0.md), or [GitHub Publishing Guide](../GITHUB_PUBLISHING_GUIDE.md).
